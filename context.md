Project Overview: AI-Enabled Battery Thermal Management SystemThis project is a simulated Battery Thermal Management System (BTMS) designed to optimize cooling for electric vehicles using an AI-driven microservices architecture. The physical system modeled consists of a battery pack with ten cylindrical 21700 lithium-ion cells inside an aluminum casing, featuring embedded circular microchannels with a 1 mm hydraulic diameter. The objective is to maintain battery temperatures between 15-45°C and ensure temperature uniformity ($\Delta T < 5^\circ C$) by dynamically optimizing the flow rate and concentration of an $Al_{2}O_{3}$/water nanofluid. Add a Redis container named message-broker using the default redis:alpine image. Expose port 6379. This will act as the asynchronous queue for our high-frequency battery telemetry data."Phase 2: Sensor Simulation EnginePrompt for Agent:"Write a Python script (simulator.py) to run in a dedicated Docker container. It must simulate real-time telemetry for ten 21700 Li-ion cells, generating JSON payloads containing voltage, current, and individual cell surface temperatures. Inject random thermal spikes (exceeding 45°C) into specific cells to simulate thermal anomalies. The script should POST this data every 1 second to http://ingestion-service:5000/telemetry."  Phase 3: Data Ingestion ServicePrompt for Agent:"Develop a Flask microservice (app.py) acting as the data ingestion pipeline. Create an endpoint POST /telemetry that receives the simulated sensor data. The service must parse the JSON, normalize the temperature values, and push the payload onto a Redis queue named battery_stream for the AI engine to process. Add this service to the docker-compose.yml."Phase 4: AI Optimization EnginePrompt for Agent:"Create a Python AI inference microservice that continuously pulls data from the battery_stream Redis queue. Write a function that evaluates the telemetry against historical computational fluid dynamics (CFD) parameters. If any cell temperature exceeds the optimal range, the service must output a JSON response recommending a specific coolant flow rate adjustment (targeting a Reynolds number between 400-700) and an optimal $Al_{2}O_{3}$/water nanoparticle concentration to achieve maximum heat transfer."  Phase 5: Digital Twin DashboardPrompt for Agent:"Build a React frontend to serve as the Digital Twin dashboard. Create a component that fetches data from the backend to display real-time statuses for the 10 battery cells. Render the cells visually, using conditional formatting (e.g., turning red for temperatures > 45°C) to highlight hotspots. Include a side panel that displays the AI Optimization Engine's active cooling recommendations and current flow rate settings."
